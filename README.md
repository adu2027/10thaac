## Program, timetable & abstracts

The interactive timetable in the "Program" section (tap a talk to read its abstract) is built from
`programme.js` (data) and `programme-ui.js` (behaviour).

- To change a time, room, title or abstract, edit `programme.js`. Maths is written in LaTeX
  between `$...$` (inline) or `$$...$$` (display) and is rendered with KaTeX.
- The downloadable PDF is `assets/ADU_book_of_abstracts.pdf`. Replace it with exactly that name
  if a new version of the book is produced; `pdfPage` in `programme.js` is the page number printed
  in the book (used for the "Open in PDF" links).
- Each talk has its own link, e.g. `index.html#talk-I1` (invited talk 1) or `#talk-C12`
  (contributed talk 12).
- During the conference (Sydney time) the current day opens automatically and the session in
  progress is marked "Now".
